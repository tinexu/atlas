# Later

- Exact drop position on the 3D timeline (ray-cast to the ribbon) instead of "today, roughly here".
- Show a short history of recovered file changes in Run History, not only in the log.
- Choose which backup to restore (not just the latest) from a settings screen.
- Import that shows a preview of what would change before applying.
- Voice commands for the Companion (Stage 06 left a slot for a speech source).
